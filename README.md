# 🐺 Play LG

> 🚀 **[https://beta.playlg.eu/](https://beta.playlg.eu/)**

Bienvenue sur le dépôt de **Play LG** ! Un projet **indépendant, gratuit et participatif** pour jouer en ligne au célèbre jeu des Loups-Garous.

## 🃏 Le Projet

Play LG a été pensé par et pour la communauté avec trois mots d'ordre :
- **Entièrement gratuit** : Pas de microtransactions, pas de pub, que du jeu.
- **Indépendant** : Développé avec passion en dehors de toute grosse structure.
- **Participatif** : La commu propose, le jeu évolue.

## ✨ Pourquoi Play LG ?

- **Une tonne de rôles** : Plus de 38 rôles jouables (dont le Pyromane, l'Ange, l'Idiot du Village, etc.)
- **Des modes de jeu uniques** : Découvrez des variantes intenses comme le *Mode Carnage*.
- **Des parties 100% personnalisables** : Créez votre salon, gérez le chat (jour/nuit), les compositions et bien plus encore pour faire votre propre partie parfaite.

## 🤝 Participer au projet

Le jeu est ouvert aux retours ! Si vous constatez un bug, avez une idée de rôle ou souhaitez simplement proposer une amélioration, n'hésitez pas à :
1. Explorer le code source de ce dépôt.
2. Ouvrir une **Issue** pour en discuter.
3. Proposer une **Pull Request** si vous vous sentez l'âme d'un développeur !
